# Prompt Engeneering Test

The purpose of this activitie is test 3 different AI with de same prompt and analyse the diferences between them. The LLMs tested was Chat GPT (free), Claude (Sonet 5.5), Gemini (auto) and I wanted them to create a website for renting and buying movies with no framework, bootstrap and tailwind CSS. 

## Prompt Used
"Work as a senior front-end developer and UI/UX designer. I need you to write the HTML and Tailwind CSS code for a complete, responsive landing page for a store.

Business: A movie rental store that now wants to sell online. The name is Lost Wild.

Market niche: The store rents out old and classic movies, on DVD or online, and emphasizes a vintage, minimalist, calm, and creative aesthetic.

Target audience: People of any gender and age who enjoy old movies.

Value proposition: The unique selling point is having movies that are very hard to find at other rental stores and an aesthetic that matches the customers’ style.

### Features:

1. Users should be able to log in easily, including with a Google account, with password verification.
2. They should be able to view the movies they have already rented, those currently rented by others, and those they have reserved, along with pricing and movie details.
3. There should be an option to purchase via a shopping cart. When purchasing or renting, the website should display a fictitious store address and the number of days available for pickup.
4. The user should also be able to view the schedule of late fees and any late fees they owe, whether already paid or pending.
5. The user should be able to log out.
5. Create an efficient system for collecting late fees, which can lead to account suspension.
6. Registering a credit card or other payment method can be a fictional process.

### Objective:
A functional website for a movie rental service that is accessible and based on UI/UX concepts, interface design, WCAG, Nielsen’s 10 heuristics, and HCI (Human-Computer Interaction). It must demonstrate customer engagement, direct sales, rentals, etc.

### Page and section structure:

A functional login page, with the option to create an account or log in.
Home page, where users will search for movies. For this section, research 20 classic movies and list them on the site for fictional sale or rental. It should include a search function, a wish list, and other creative features.
User profile, with information about rentals.
Fines section.
Registered cards section.
“About Us” section—to be created—explaining that the company wants to keep these movies alive.

### Visual style and design:

Color palette: draw inspiration from the color palettes attached as JPG files.

Typography: modern and minimalist fonts, which can be mixed with other styles if they complement each other.

Visual references: use the references attached as JPG files.

Note: avoid generic AI-generated styles and draw inspiration from Behance designers whose work matches the proposed style.

Technologies: HTML, CSS, and JavaScript, following best coding practices and Clean Code principles in file structure. Use Tailwind!

Responsiveness: The website must be 100% optimized for smartphones and tablets (Mobile-First).

Interactivity: Create simple yet engaging transitions and hover effects that enhance the user experience.

Architecture: HTML, CSS, and JS files should be placed in the root folder, with separate folders for the other pages on the site and for the assets.
